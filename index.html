ℹ️ About

About AEL Color Extractor

A canvas-based color extraction tool by AEL Digital Studio

📋 Overview

AEL Image Color Extractor uses canvas-based pixel analysis and smart color quantization to extract dominant colors from any image. No server required — everything runs in your browser.

⚡ Features

  • 3-16 color extraction with quality control
  • Smart color quantization algorithm
  • 5 export formats (CSS, Tailwind, JSON, SVG, TXT)
  • Canvas-based pixel analysis
  • Zero server dependencies
  • Copy-paste ready exports

🛠 Tech Stack

  • HTML5 — Semantic structure
  • CSS3 — Glassmorphism, grid, flexbox
  • JavaScript — Canvas API, color quantization, file API
